# Recommended URL map

| Host | Purpose |
|---|---|
| `onecore.co.ke` | Corporate website |
| `app.onecore.co.ke` | Customer workspace |
| `admin.onecore.co.ke` | Superadmin and operations |
| `developers.onecore.co.ke` | Developer portal |
| `docs.onecore.co.ke` | Documentation |
| `support.onecore.co.ke` | Support portal |
| `status.onecore.co.ke` | Public service status |
| `files.onecore.co.ke` | Secure files |
| `partners.onecore.co.ke` | Partner portal |
| `community.onecore.co.ke` | Community |
| `careers.onecore.co.ke` | Careers |
| `trust.onecore.co.ke` | Trust centre |
| `api.onecore.co.ke` | API gateway |
| `auth.onecore.co.ke` | Identity |
| `search.onecore.co.ke` | Universal search |
| `media.onecore.co.ke` | Media origin |
| `cdn.onecore.co.ke` | Static asset CDN |
| `events.onecore.co.ke` | Events and webinars |

These are logical entry points. They can share a gateway/frontend where appropriate; DNS, TLS, routing and access policies remain deployment responsibilities.
