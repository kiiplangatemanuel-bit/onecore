Scheduled campaigns and reusable communications

Templates are versioned. Saved audiences support nested AND/OR groups. Each scheduled occurrence creates a distinct campaign, refreshes consent and audience membership, and uses the existing delivery/retry/callback pipeline. The worker must be running.

Reusable message template

Variables: {{first_name}}, {{last_name}}, {{full_name}}, {{email}}, {{phone}}, {{company}}, {{campaign_name}}. Saving an existing name creates the next version; existing schedules keep their pinned version.
